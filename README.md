# Mi Negocio

App para controlar las ventas de un negocio o kiosco desde el celular: ventas, stock, compras al mayorista, fiado, apertura y cierre de caja, gastos, balance del día y del mes, código de barras con la cámara y Excel.

**Abrir e instalar:** https://daniandroiddl-cmd.github.io/mi-negocio/

Se instala desde el navegador (botón "Instalar") y funciona sin internet. Los datos quedan guardados solo en el celular de cada persona.
